# Как получить состояние «Было»

## Запуск базовой версии

1. Найди, как проект запускается: `README`, скрипты `package.json` (`dev`, `start`), `.claude/launch.json`,
   `docker-compose.yml`, `Makefile`, `AGENTS.md`/`CLAUDE.md`.
2. `git worktree add ../<repo>-pr-before <base>`. Базой считай `origin/<target-branch>` PR или
   `git merge-base HEAD origin/main`.
3. Поставь зависимости заново (`npm ci` / `pnpm i --frozen-lockfile` / …). Не делай симлинк на
   `node_modules` текущей ветки: зависимости могли измениться.
4. Запусти базовую версию на свободных портах (обычно через `PORT=…`, `--port …` или переменные
   окружения фронтенда и API), чтобы она работала параллельно с новой.

## Данные и база

- Обе версии должны показывать **одинаковые данные**, иначе разница на кадрах будет не только из-за кода.
- Если в PR есть миграции, сначала сними «Было» на базе до миграций, потом примени миграции и сними
  «После». Если API отказывается работать со схемой «из будущего», подними отдельную scratch-базу для
  базовой версии (многие проекты умеют создавать её для e2e-тестов) и прогони тот же сид.
- Используй сид или демо-скрипт проекта. Если подходящих данных нет, создай их через API или UI в обеих
  версиях одинаковым скриптом.

## Авторизация

По порядку предпочтения:

1. Существующие e2e-хелперы проекта, которые создают сессию (поищи `createSession`, `storageState`, `login`
   в тестах).
2. Демо-учётки из сидов (часто лежат в `.env*`-файлах, которые не коммитятся). Никогда не выводи
   пароли в лог и PR.
3. Залогиниться один раз через UI в `--setup` скрипте и сохранить `context.storageState({ path: 'auth.json' })`,
   потом передавать `--storage-state auth.json` в `shoot.mjs`/`record.mjs`. Удали `auth.json` после работы,
   не коммить его.

## Если «Было» честно не получить

Например, базовая версия не собирается, нужен внешний сервис или изменение касается продакшен-окружения.
Тогда:

- проверь, нет ли «Было» в предыдущих PR, в задаче или в `docs/` (скриншоты старых версий); такой кадр
  можно использовать с подписью, откуда он;
- если и этого нет, напиши в PR: «Скриншот „Было“ не приложен: <конкретная причина>». Покажи «Стало» и
  опиши словами, как было.

Подделывать «Было», то есть править DOM, откатывать стили в DevTools или рисовать макет, нельзя.

## Мобильные приложения (iOS Simulator, Android Emulator)

Запуск «Было» и «Стало»:
- Обе версии собираются из своих checkout (`../<repo>-pr-before` и рабочий), у каждой свой Metro
  на отдельном порту: `npx expo start --port 8082` и `--port 8083` (или `react-native start --port`).
  Приложение в симуляторе переключай на нужный bundler, а не пересобирай натив без нужды.
- `node_modules` для worktree ставь честно (`npm ci`). Копия через APFS или симлинк ломает резолв
  Metro.
- Если экран за логином и демо-учётки нет, временный обход авторизации в коде допустим только в
  обеих версиях одинаково. Откати его до коммита и упомяни в PR.

Снимки и запись (зови утилиты напрямую, без сложных shell-функций: zsh ломает `$var[1]` и
`$x:r`, а ffmpeg — неэкранированные `:` и `,` в фильтрах):

```bash
# iOS
xcrun simctl io booted screenshot raw-before.png
xcrun simctl io booted recordVideo --codec=h264 raw-before.mov   # стоп: Ctrl+C (или kill -INT <pid>)
# Android
adb exec-out screencap -p > raw-before.png
adb shell screenrecord --bit-rate 12000000 /sdcard/rec.mp4 && adb pull /sdcard/rec.mp4 raw-before.mp4
```

Обработка:
- Метки на скриншоте ставь через `shoot.mjs --image raw-before.png --box "x,y,w,h => подпись"
  --scale 3`. Координаты задаются в пикселях картинки, `--scale` — плотность экрана устройства
  (у iPhone 3, у большинства Android 2.6–3).
- GIF из записи делай через `record.mjs --video raw-before.mov --start 1.2 --duration 6 --out
  docs/pr/<slug>/03-tab-before.gif`. Ширина по умолчанию 720px для портрета, и GitHub показывает
  её чётко даже в узкой ячейке. `--crop x,y,w,h` убирает статус-бар и пустоту, `--box "x,y,w,h"`
  рисует рамку на всё видео. Начало действия ищи по первому кадру с изменением:
  `ffmpeg -i raw.mov -vf "select='gt(scene,0.01)',showinfo" -f null - 2>&1 | grep pts_time | head`.
- Мобильные пары ставь рядом в таблице: они узкие.

## Другие не-веб интерфейсы

- Десктоп и TUI: системный скриншот окна или вывод через `shoot.mjs --text`.
- Библиотеки: вывод примера использования или тестов через `--text`, а для структурных изменений диаграмма.

## Уборка

Останови серверы, которые запускал, удали `../<repo>-pr-before` (`git worktree remove --force`),
scratch-базы и временные `auth.json`.
